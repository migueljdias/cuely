# Security

Please report a vulnerability privately through GitHub's private vulnerability reporting: https://github.com/migueljdias/cuely/security/advisories/new

Please don't open a public issue for it.

## Scope

- The MCP server at https://cuely.dev/api/mcp and its OAuth and API-key handling
- The website and account pages at https://cuely.dev and https://app.cuely.dev
- The data jobs in `.github/workflows` that publish to `main`
